Inscribed Square Research Program

A dual-track investigation of the Toeplitz conjecture: every continuous Jordan curve in the plane contains four distinct points forming a nondegenerate square.

Scope. This program does not claim a proof of the full conjecture for all Jordan curves. We publish exact finite geometry, reproducible obstruction audits, and rigorous partial results—including a completed benchmark noncollapse theorem for the canonical double spiral and a large verified residual-routing engine.

Two complementary tracks

Track A — Computational laboratory (squarepeg)

An exact rational polygon square solver, certificate schema, and a directive protocol: each milestone defines theorem targets, clean-room audits, frozen manifests, and regression gates. Recent global-geometry work (Directives 058–061) builds a residual ledger and routes curve-level failures into named global obstructions on a certified Cantor fixture—without claiming universality.

Track B — Microlocal / Floer analytic spine (Codex archive)

Independent writeups on Asano–Ike–style normal tests, double-spiral quantization, and Option B benchmarks. Major 2026 results include uniform annular kernel removal (complementary transition maps vanish for r′ ≤ r/5 before source pairing), an exact curved-front pushforward for epigraph sources, and a spectral noncollapse theorem for the canonical double spiral with positive side-length bound.
