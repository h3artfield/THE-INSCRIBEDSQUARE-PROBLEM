Progress on the Inscribed Square Problem:
Exact Verification, Residual Geometry, and Microlocal Reductions

Abstract. We report on a multi-year structured research program targeting the Toeplitz conjecture. We separate (i) an exact computational laboratory for finite polygons and obstruction routing on certified tree models, and (ii) a microlocal analytic line studying Asano–Ike normal tests on the canonical double spiral. We prove several local and benchmark results, document conjectural global targets, and identify the precise remaining analytic obstruction after uniform removal of outer normal-test kernel terms. We do not assert a proof of the conjecture for all Jordan curves.

1. Introduction

The inscribed square problem asks whether every Jordan curve in ℝ² contains four distinct points that are vertices of a nondegenerate square. Approximate squares on smooth or polygonal approximants are abundant; the hard question is nondegeneracy under C⁰ limits—squares may collapse to the diagonal.

Our program follows two principles: (1) every claim carries an explicit status label (PROVED_LOCALLY, CONJECTURAL, SOURCE_THEOREM, etc.); (2) universal conclusions are never inferred from numerical or fixture-local certificates alone.

2. Track A — The squarepeg computational laboratory

2.1 Exact finite geometry (Directives 001–002)

We built PolygonCurve with exact rational coordinates and a square solver that assembles the 6×6 linear system for cyclic edge quadruples. Rank-6 systems yield isolated certificates; rank-5 systems are represented as exact one-parameter affine families (AffineSquareFamily1D)—not sampled points. An independent validator re-assembles equations. We wrote a finite enumeration completeness argument (T009).

2.2 Spectral and defect-extraction spine (Directives 003–057)

Directives 003–010 audit spectral axioms and midpoint nonflatness; later directives formalize intrusion trees, winding layers, augmented gate measures, transition exhaustion, and—through Directive 057—coherent route extraction (T103 clean-room verified on the binary equal-ratio Cantor fixture). These modules implement a proof-engineering discipline: each theorem target has a certificate function, clean-room questionnaire, and pytest gate.

2.3 Global residual ledger and geometry (Directives 058–061)

Directive 058 consolidates global residuals, removes spurious independent classes, and publishes a T045R attack map. Directive 059 classifies positive-scale cluster geometry at curve level (T112–T115). Directive 060 classifies non-Jordan saturation hulls (T116–T120). Directive 061 (implementation complete, milestone freeze pending) classifies parameter-disconnected limit geometry (T121–T125).

On the certified Cantor fixture, Outcomes A eliminate or route the targeted residuals into named globals (PARAMETER_DISCONNECTED_LIMIT, INFINITE_CENTER_GEOMETRY, etc.). T045R (full universal extraction) remains CONJECTURAL_FULL_EXTRACTION.

3. Track B — Microlocal analytic reductions (companion archive)

Parallel to the repository, a structured note series develops Option B and universal-proof diagnostics for the canonical double spiral. The following are the principal novel proved analytic results (as documented in that archive):

3.1 Uniform annular removal of complementary kernel terms

Split the normal-test kernel Mr,η into inner truncation Nr,η = Mr,η ⊗ k|y₁−y₂|<r/2 and complement Dr,η. For r′ ≤ r/5, disjoint closed supports force RHom(Dr′,η′, Dr,η) = 0 with coherent nullhomotopies. This zero transformation survives composition with the source sequence, derived inverse limits, and neighborhood colimits—so the outer annulus may be removed rigorously in the final pairing, reducing to the truncated cone Nr,η.

3.2 Local source pushforward benchmarks

  • Locally constant source on the full test fiber → zero pushforward.
  • Flat / curved epigraph sources → explicit spherical-boundary sublevel complexes; degree-two contributions possible.

These are model calculations. They do not yet identify the full capped-spiral source An with a single epigraph.

3.3 Cap-front cluster and remaining obstruction

The analytic cap yields four product branches at three action levels, with gaps of order O(εn⁸). A fixed-radius test eventually meets multiple branches; isolated epigraph formulas omit attaching maps. The remaining work is an ordinary sheaf complex for the cluster (including arm terms), composition with Nr,η, and RHom(−, G) against the actual wild target. Final kernel/cokernel spaces are not computed.

3.4 Benchmark spectral noncollapse (canonical double spiral)

Separately, we complete a noncollapse argument for the canonical double spiral: smooth approximants carry degree-one spectral generators with a uniform side-length lower bound, yielding a nondegenerate limiting square on the benchmark curve. This is not the universal Jordan theorem; it does not compute the singular diagonal restriction map rC: M → N for all curves.

3.5 Universal status

The archive’s universal-proof-status.md maintains that the universal Toeplitz theorem is not established. Recent results sharpen benchmarks, remove outer kernel noise, and name the live obstruction (truncated cone × spiral attaching × pairing with G).

5. Reproducibility

Clone the repository, install with pip install -e ".[dev]", run pytest -m audit tests/test_frozen_certificate_snapshot.py for manifest consistency (~1s), or directive fast suites as documented on the tests page.

6. Conclusion

We have materially advanced the inscribed square problem along two rigorous fronts: a large, frozen, test-gated obstruction-routing engine for tree-level geometry, and a sequence of microlocal reductions culminating in uniform annular kernel removal and a completed double-spiral noncollapse benchmark. The central universal question remains open; the next analytic focus is the full spiral cap cluster paired with the truncated cone and actual target G.
