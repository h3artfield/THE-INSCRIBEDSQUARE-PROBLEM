# Quotient Twisted Pairing

Free \(\mathbb Z_4\)-action on \(U\) induces \(\overline U=U/\langle\tau\rangle\).

Rhombus class \([R]\) descends to \([\overline R]\).

Sign line \(L_\chi\) has \(w_1(L_\chi)\neq0\) on \(\overline Z\cong S^1\).

**Pairing:**
\[
\langle w_1(L_\chi),[\overline Z]_2\rangle = 1
\]

Preserved under homotopy preserving boundary exclusion.
