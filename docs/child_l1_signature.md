# CHILD_L1_SIGNATURE (Directive 042)

A countably branching node satisfies `CHILD_L1_SIGNATURE` when:

1. \(L(v)<\infty\);
2. \(\tau_v(N)\to0\);
3. intrinsic child-crosscut areas absolutely summable;
4. Jordan hull preserved;
5. uniform local \(L_J(v)\) vanishing on short intervals.

Geometric sufficient condition: \(|\Delta_{w_i}|\le C M_{w_i}r_{w_i}\) and \(\sum_i M_{w_i}r_{w_i}<\infty\).
