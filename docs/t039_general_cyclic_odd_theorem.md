# T039 — General Cyclic-Odd Theorem

## Statement

**T039 (CONJECTURAL_GENERALIZATION):** Let \(\gamma\) carry a compact cyclic-invariant rhombus continuation component in collision-free \(U\). If:

1. normal rhombus mod-2 degree \(\ne0\);
2. quotient cycle pairs nontrivially with \(L_\chi\) from \(D(\tau u)=-D(u)\);
3. side and collision margins positive;

then every sufficiently small \(C^0\) curve perturbation contains a square in \(U\).
