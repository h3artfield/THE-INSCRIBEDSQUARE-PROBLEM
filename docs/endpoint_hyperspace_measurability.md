# Endpoint Hyperspace Measurability (Directive 046)

Let \(\mathcal K(\overline B)\) be nonempty compact subsets of the normalized disk with Hausdorff distance.

## Results

- \(\xi\mapsto K_j(\xi)\) is Borel for each finite \(j\) (finite truncation of end path).
- \(\xi\mapsto\Phi(\xi)\) is measurable as a map into \(\mathcal K(\overline B)\) via decreasing compact-set limits (Effros Borel structure on hyperspace).

**Theorem used:** measurable limits of nested compact sets in Polish hyperspace.

**Module:** `endpoint_hyperspace.py`
