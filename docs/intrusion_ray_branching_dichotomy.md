# Intrusion Ray–Branching Dichotomy — T078 (Directive 040)

Every infinite rooted intrusion tree has:

1. an infinite ray;
2. arbitrarily large finite branching;
3. a node with infinitely many children.

For locally finite trees, infinite height implies an infinite ray (König's lemma).

**Status.** PROVED_LOCALLY for finite truncations.

**Implementation.** `ray_branching_dichotomy.py`
