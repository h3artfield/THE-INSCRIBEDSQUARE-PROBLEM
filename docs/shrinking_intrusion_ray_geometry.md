# Shrinking Intrusion Ray Geometry (Directive 040)

Ray scale classes:

- positive-scale;
- shrinking;
- plateau-jump;
- geometric-decay (\(\lambda_- \le r_{j+1}/r_j \le \lambda_+\)).

Positive-scale rays route to annular, finite-center, nonannular, or non-Jordan subclasses without shrinking surgery.

**Implementation.** `intrusion_ray_geometry.py`
