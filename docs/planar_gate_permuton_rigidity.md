# Planar Gate-Permuton Rigidity — T077 (Directive 039)

## T077

A genuinely diffuse Jordan gate permuton cannot arise from a sequence with simultaneously:

1. uniformly bounded depth and branching;
2. Jordan saturation hulls;
3. uniformly finite center complexity;
4. no parameter-disconnected concentration;
5. no positive-scale nonannular branch.

**Status.** `CONJECTURAL_RIGIDITY_TARGET`; partial via T077-A for bounded-depth class.

Unbounded depth/branching routes to explicit residuals: infinite intrusion, unbounded branching, infinite center, non-Jordan hull, parameter-disconnected.

**Implementation.** `planar_permuton_rigidity.py`
