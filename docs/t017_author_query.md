## Body

We are preparing a note combining:

1. **Boedihardjo–Geng** (arXiv:1309.1576v2): simple piecewise-linear Jordan interpolation and \(q\)-variation convergence for \(q>p\).
2. **Asano–Ike** (arXiv:2412.21057v3): Theorem 1.1 (continuous Legendrian lift \(\Rightarrow\) all \(\theta\)-rectangles).
3. A **local lemma** (controlled \(C^1\) smoothing of polygonal Jordan curves with small \((S-P)\) variation under a common parametrization).

**Theorem (proposed):** If \(c:S^1\to\mathbb R^2\) is a Jordan curve with finite \(p\)-variation for some \(1\le p<2\), then \(c\) satisfies the hypotheses of Theorem 1.1.

**Question:** Is this corollary already known to the authors, or does Theorem 1.1 / Remark 5.6 already cover finite \(p\)-variation curves implicitly?

**Novelty language we plan to use:**

> This appears to be an immediate synthesis of existing interpolation and microlocal peg results, with the controlled \(C^1\) smoothing lemma supplied here.

We would appreciate any pointer to prior work or a correction if the statement is false.
