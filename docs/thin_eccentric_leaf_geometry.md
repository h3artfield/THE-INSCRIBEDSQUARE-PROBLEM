# Thin Eccentric Leaf Geometry (Directive 034)

Width \(w(L)=\inf_\theta(\max x\cdot e_\theta-\min x\cdot e_\theta)\).

Eccentricity \(\mathrm{ecc}(L)=\mathrm{diam}(L)/w(L)\) — valid when inradius is zero.

`THIN_LEAF_ORDERED`: Jordan two-gate, \(w/\mathrm{diam}\to0\), aligned, summable width mass.

**Implementation.** `thin_leaf_geometry.py`
