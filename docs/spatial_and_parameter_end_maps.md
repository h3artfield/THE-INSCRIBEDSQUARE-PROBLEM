# Spatial and Parameter End Maps

## Spatial map \(\Phi(\xi)\)

\[
\Phi(\xi) = \bigcap_j \overline{H_{v_j}}
\]

when a singleton; otherwise classified as continuum, non-nested, noncompact, or non-Jordan.

## Parameter map \(\Psi(\xi)\)

Limiting parameter support; distinguishes spatial diffusion from parameter disconnection.

**Module:** `end_spatial_map.py`
