# Mixed Branching Tree Exhaustion (Directive 042)

Two-parameter truncation \(F_{D,N}\): depth \(\le D\), first \(N\) children at each countably branching node.

Compatible exhaustions; limit order: \(n\), \(\delta\), \(N(D,\delta)\), \(D\).

Tail decomposition: deep-generation, large-child-index, T080 ray, retained skeleton.
