# Pair Interaction Concentration (Directive 056)

Absolute pair-interaction measure \(|\Omega|_\wedge\) weighted by \(|\Delta(m)\wedge\Delta(m')|\).

Nonsummable pair tails trichotomy routes to:

1. spatial/parameter concentration;
2. finite-center splitting;
3. diffuse interaction (via T077-A);
4. collision concentration;
5. positive-scale interaction.
