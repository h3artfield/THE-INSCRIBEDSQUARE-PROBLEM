# Parameter Support Geometry (Directive 061)

Curve-level parameter support is defined from leaf param-intervals and gap mass — independent of Cantor fixture encoding.

Support classes: `CONNECTED`, `FINITE_DISCONNECTED`, `COUNTABLE_DISCONNECTED`, `CANTOR_DISCONNECTED`, `DUST_LIKE`, `HARMLESS_QUOTIENT`.

**Module:** `parameter_support.py`

**Status:** PROVED_LOCALLY on certified fixture (connected support, no true disconnection).
