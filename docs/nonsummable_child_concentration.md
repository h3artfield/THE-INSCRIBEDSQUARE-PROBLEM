# Nonsummable Child Concentration

Normalize parent hull \(H_v\) to diameter one. Child signature measure:

\[
\nu_v=\frac{1}{Z_v}\sum_i \operatorname{SigMass}(w_i)\delta_{c_i}.
\]

## Concentration–compactness alternative

1. **Concentrated** — shrinking balls capture fixed mass → T064/T064D/T062 routes
2. **Finite-center** — at most \(K\) separated regions → T062
3. **Diffuse** — `DIFFUSE_CHILD_CENTER_NODE`
4. **Hull degeneration** — Jordan-disk hypotheses fail
