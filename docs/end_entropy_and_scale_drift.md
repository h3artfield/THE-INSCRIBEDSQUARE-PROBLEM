# End Entropy and Scale Drift (Directive 048)

Child probabilities \(p_w=M(w)/M(v)\); entropy \(H(v)=-\sum p_w\log p_w\); scale drift \(\Lambda(v)=\sum p_w\log(r(v)/r(w))\).

Density drift \(\log D(w)-\log D(v)\) related to entropy and excess — not a martingale identity.
