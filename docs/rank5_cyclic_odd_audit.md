# Rank-5 Cyclic-Odd Audit

Rank-5 polygon families from the exact solver are **not** automatically `CYCLIC_ODD_CERTIFIED`.

Each genuine compact family requires separate:

- rhombus continuation class computation;
- free cyclic action verification;
- sign-line \(w_1\) pairing.

Default classification: **`UNPROTECTED`** or **`ASSIGNMENT_ARTIFACT`**.

Implementation: `rank5_cyclic_audit.py`
