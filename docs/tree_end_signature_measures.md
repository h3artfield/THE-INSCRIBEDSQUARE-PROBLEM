# Tree End Signature Measures

Construct end space \(\partial\mathcal T\) and signature end measure \(\mu_{\mathrm{end}}\).

## Independence

End mass on leaf nodes is verified independent of depth and mixed \(F_{D,N}\) exhaustions.

## Classification

- finite atomic / countably atomic (summable / nonsummable)
- nonatomic diffuse

Spatial pushforward classes:

- `SINGLE_POINT_END_CONCENTRATION`
- `FINITE_CENTER_END_MEASURE`
- `CANTOR_END_MEASURE`
- `DIFFUSE_SPATIAL_END_MEASURE`
- `NONINJECTIVE_END_MAP`
