# Concentrated Parameter Blocks (Directive 032)

Extract **consecutive** parameter/gate block \(B_n\) with \(|\mathbb A_{B_n}|\ge c_1\varepsilon_0\).

Distinguishes:
- parameter-consecutive block in spatial ball;
- spatial-only concentration (`DISCONNECTED_CONCENTRATION` residual).

Original-scale diameter \(r_n' \le C\rho_n r_n = o(r_n)\).

**Implementation.** `concentrated_parameter_block.py`
