# Finite Subtree Surgery Exhaustion (Directive 041)

Truncation \(F_N=\{v:\mathrm{depth}(v)\le N,\ r_v\ge\eta_N\}\).

Maximal surgery nodes form a valid forest; crosscuts on incomparable nodes are disjoint.

Exhaustion: \(|Q_N-P|_\infty\le\sup_{v\notin F_N}r_v\to0\).
