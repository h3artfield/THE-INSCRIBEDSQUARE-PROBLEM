# Thick/Thin/Multigate Diffuse Alternative — T067R (Directive 034)

Every diffuse same-sign lamination satisfies one of:

1. T066 ordered two-gate;
2. T068 finite-multigate;
3. T069 thin eccentric;

5. explicit residual.
