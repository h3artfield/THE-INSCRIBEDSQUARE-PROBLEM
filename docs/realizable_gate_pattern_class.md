# Realizable Gate Pattern Class (Directive 039)

## Class \(\mathcal P_J\)

Finite cyclic permutations realizable by finite-intrusion Jordan gate systems.

Invariance audited under:

- cyclic shifts (membership preserved);
- reversal;
- gate deletion;
- consecutive parameter block restriction.

Pattern containment is tested via `pattern_containment`; hereditary closure is **not proved**.

Forbidden patterns 2413/3142: preliminary verdict **UNRESOLVED** (reconnaissance).
