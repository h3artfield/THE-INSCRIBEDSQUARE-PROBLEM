# T041 — Shrinking-Support Obstruction

**Status:** PROVED_LOCALLY (Directive 023)

## Statement

If four candidate square vertices lie in a set of diameter \(r\), every pairwise distance is at most \(r\), hence any square supported entirely in that set satisfies \(\operatorname{side}(Q) \le r\).

If packet diameters \(r_n \to 0\), no square using four vertices entirely inside those packets can be nondegenerate on the limiting curve.

## Consequence

Packet-level T036-N1-ANN cannot alone resolve the shrinking-scale branch; surgery or positive-scale subsequence required.
