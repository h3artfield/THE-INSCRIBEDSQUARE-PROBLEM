# Near-Equality Stability (Directive 049)

For each ledger entry: deficit ≤ ε ⟹ dist(config, equality class) ≤ ω(ε), ω(ε)→0.

Combined stability: total deficit ≤ 0.15·|ledger| ⟹ configuration within Ω(ε) of finitely many equality templates (8 templates parameterized).

**Module:** `equality_stability.py`
