# Coherent Route Subsystems (Directive 057)

Coherence types:

- COHERENT_RAY
- COHERENT_FINITE_BRANCH_TREE
- COHERENT_BUSHY_TREE
- COHERENT_MEASURE_SUBTREE
- COHERENT_ANTICHAIN_EXHAUSTION

A coherent subsystem is ancestry closed, retains positive \(\Phi_{\mathrm{end}}\)-signature at arbitrary depth, and carries one uniform route.

**Module:** `coherent_route_subsystem.py`
