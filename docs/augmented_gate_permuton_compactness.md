# Augmented Gate Permuton Compactness (Directive 039)

## Geometric measure

\[
\widetilde\mu_N = \frac1N \sum_{i=1}^N \delta_{(x_i,y_i,z_i,s_i,d_i)}
\]

with boundary order, parameter order, normalized spatial position, scale, and intrusion depth.

Weak limit extraction retains spatial, scale, and depth data. Order marginal \(\mu = (x,y)_\#\widetilde\mu\).

## Genuinely diffuse criteria

Five conditions excluding solved branches: not countably monotone-supported; no shrinking-ball mass; no finite-center mass; bounded depth for finite-tree; Jordan hull.
