# Relative Rhombus Continuation

**Framework:** Relative singular homology with \(\mathbb Z_2\) coefficients.

## Class

\[
[R] \in H_1(U,\partial_\nu U;\mathbb Z_2)
\]

defined by mod-2 degree of \(G:U\to\mathbb R^3\) on normal fibers, constant when \(G\neq0\) on \(\partial_\nu U\).

## Homotopy invariance (Lemma 16)

If \(G_s\) is a homotopy with \(G_s\neq0\) on \(\partial_\nu U\) for all \(s\), then \([R_s]\) is constant.

## Perturbation

For \(\|\gamma-\gamma_0\|_\infty<\eta\) with \(E_G(\eta)<m_G\), boundary exclusion persists ⇒ class preserved.
