# Measure-Valued Neutral Transitions (Directive 052)

For unbounded child count, replace finite child lists by measure \(\mathsf K_v\):

\[
X(v)=E(v)+\int A(v,y)X(y)\,d\mathsf K_v(y),
\qquad
\int |X(y)|_\star\,d\mathsf K_v(y)<\infty.
\]

Tightness verified after routing concentration, infinite-center, T081I, positive scale, parameter disconnection, non-Jordan branches.
