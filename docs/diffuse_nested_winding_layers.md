# Diffuse Nested Winding Layers (Directive 032)

Diffuse regime: winding depth \(d_n\to\infty\) or bounded depth caps \(W_n^+\).

Nested chain \(\Omega_{n,1}\supset\cdots\supset\Omega_{n,d_n}\) with scale ratios:
- uniform contraction;
- slow contraction (annular collar candidate);
- scale jump (returns to T064);
- multicenter drift.

Nesting **not** promoted to annular geometry without proof.
