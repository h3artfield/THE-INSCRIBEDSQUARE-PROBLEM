# Continuum-End Positive-Scale Reduction — T091 (Directive 046)

## Statement

If a nested Jordan end has \(\operatorname{diam}\Phi(\xi)>0\), the corresponding ray has positive limiting spatial scale and belongs to one of:

1. certified annular positive-scale geometry;
2. positive-scale finite-center geometry;
3. positive-scale nonannular geometry;
4. non-Jordan or incompatible-hull degeneration.

## Key lemma

Persistent hull diameter: \(\lim_j\operatorname{diam}H_{v_j}\ge d_\Phi(\xi)>0\). Such ends cannot be genuinely shrinking intrusion ends.
