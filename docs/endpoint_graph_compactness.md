# Endpoint Graph Compactness (Directive 046)

Define \(\operatorname{Graph}(\Phi)=\{(\xi,x):x\in\Phi(\xi)\}\subset\partial\mathcal T\times\mathbb R^2\).

## Repair of Directive 045

Graph compactness replaces the failed requirement that \(\Phi\) be point-valued a.e. before spatial analysis.

- Graph is Borel under the tangent topology.
- Normalized tangent sequences: Hausdorff convergence on graph truncations flags tangent graph convergence.

**Module:** `endpoint_graph_compactness.py`
