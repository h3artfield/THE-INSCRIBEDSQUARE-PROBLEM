# Diffuse Winding Lamination Definition (Directive 033)

A `DIFFUSE_NONCROSSING_WINDING_LAMINATION` consists of:

1. compact planar support K;
2. partially ordered essential leaves;
3. nesting/disjointness;
4. transverse measure μ;
5. orientation sign;
6. gate-order and parameter-support data;
7. winding mass ∫ Area(L) dμ(L);
8. diffuse limit: no atom carrying fixed mass fraction.

Defined independently of implementation labels in `winding_lamination.py`.
